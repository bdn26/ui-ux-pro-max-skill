# Placeholder imagery

This theme uses CSS-only placeholder blocks (`beautydna_placeholder()` in
`inc/template-tags.php`) instead of static placeholder image files, so
there's nothing to replace here directly — swap content via the
Customizer, Featured Images, and category/product images in wp-admin (see
the main README's **Setup** section).

Drop real exported assets in this folder only if you need a shared,
non-WordPress-media static image (e.g. a brand mark used in an `<img>` tag
outside the Media Library).
